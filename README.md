# arbol-sdk

The Arbol API over HTTPS for Rust services. Its types, operations and client methods are generated by
[Cloudflare Forge](https://github.com/cloudflare/forge) from the platform's public OpenAPI,
[`https://api.getarbol.com/openapi.json`](https://api.getarbol.com/openapi.json), like
[`@arbol-ai/sdk`](https://www.npmjs.com/package/@arbol-ai/sdk) for TypeScript. It uses `reqwest` with
rustls, `serde` and `thiserror`, runs on any Tokio runtime, and needs Rust 1.85 or newer.

## Install

Add it as a git dependency:

```toml
[dependencies]
arbol-sdk = { git = "https://github.com/getarbol/project-arbol-sdk-rust" }
```

Pin a commit with `rev = "<commit>"` for reproducible builds. The library is `arbol_sdk`;
`arbol_sdk::RELEASE` names the API release it was generated from, such as `1.20261019.4056`. It is not
on crates.io yet; releases there may come later.

## Usage

```rust
use arbol_sdk::{Client, Credential, types};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let arbol = Client::new(Credential::ApiKey(std::env::var("ARBOL_API_KEY")?))?;
    let input = types::AgendaAppointmentsListInput {
        from: Some("2026-10-12T00:00:00Z".into()),
        to: Some("2026-10-19T00:00:00Z".into()),
        ..Default::default()
    };
    let page = arbol.agenda().appointments().list(&input).await?;
    println!("{page:?}");
    Ok(())
}
```

Every operation is a method named after its public name: `account.apiKeys.create` is
`arbol.account().api_keys().create(&input)`, with `types::AccountApiKeysCreateInput` in and
`types::AccountApiKeysCreateOutput` out.

- **One credential:** an API key (`arb_live_…`) for a machine, or a person's access token for the
  audience `https://api.getarbol.com`. HTTPS origins only; `Client::with_base_url` names another
  trusted deployment.
- **Nothing is retried, and no redirect is followed.** A failure is an `arbol_sdk::Error` with the
  owner's `code`, the `request_id` and an `outcome`: `Refused`, `NotSent`, or `Unknown` for a write
  that may have happened. Reconcile an unknown outcome with its owner before repeating the call.
- **A response is bounded** by its operation's limit, and the success envelope is unwrapped: a method
  returns the `data`.
- **Types follow the schema.** An optional field is `Option<T>` and is left out when `None`. An optional
  field that may also be null is `Option<Option<T>>`, where `Some(None)` sends `null`. A union is an
  untagged enum whose members' literal fields tell them apart. What Rust cannot say exactly is
  `serde_json::Value`.

## How it is generated

| Path                             | What it is                                                                                        |
| -------------------------------- | ------------------------------------------------------------------------------------------------- |
| `src/lib.rs`                     | The transport, written by hand: credential, HTTPS, limits, failures                               |
| `src/generated/`                 | The plugin's output, never edited: `types.rs`, `operations.rs`, `client.rs`, `mod.rs`             |
| `src/generated/generation.json`  | Provenance: the OpenAPI release and hashes, Forge's commit, the plugin's source, each file's hash |
| `generation/plugins/sdk-rust.ts` | The Forge plugin that writes `src/generated/`                                                     |
| `generation/generate.ts`         | Prepares the generation document from the public OpenAPI and runs the plugin                      |
| `generation/forge-lock.json`     | The pinned Forge commit, and the hash of every vendored plugin-library file                       |

Cargo.toml records the OpenAPI the crate was generated from:

```toml
[package.metadata.arbol.openapi]
release = "1.20261019.4056"   # the OpenAPI's info.version
sha256 = "a160f98d…"          # SHA-256 of its canonical JSON without info.version (generation/openapi-hash.ts)
```

Forge is pinned at
[`7f86447210b7bea3779bfdab3cd5655eade0eadb`](https://github.com/cloudflare/forge/tree/7f86447210b7bea3779bfdab3cd5655eade0eadb)
(0.1.0). `scripts/forge.ts` builds its binary from that commit with `cargo install --locked` into
`.forge/` (no prebuilt binary is downloaded) and checks its version; the plugin library is vendored in
`generation/vendor/forge`, Apache-2.0, every file hashed in `forge-lock.json` and checked before use.
The plugin is compiled to a WebAssembly component with jco.

`generate.ts` writes one document for Forge: the public OpenAPI's operations, each carrying its
prepared operation, and every schema a client types. The plugin checks every method Forge models
against its operation (group path, name, HTTP method, path), so an operation that is dropped or renamed
fails generation instead of passing unnoticed. Generation refuses private or incomplete operations,
remote references, and titles or descriptions that could leave the comments holding them.

## Regenerating

Generation runs by hand. To move the crate to the OpenAPI the API serves now:

```sh
bun install
bun run forge       # build the pinned Cloudflare Forge with cargo into .forge/ (once)
bun run openapi     # download https://api.getarbol.com/openapi.json
bun run generate    # src/generated/ and Cargo.toml's [package.metadata.arbol.openapi] from openapi.json
bun run verify      # typecheck, generation tests, cargo fmt --check, clippy -D warnings, cargo test
```

`bun run hash` prints the downloaded OpenAPI's content hash; when it equals the `sha256` Cargo.toml
records, the API is unchanged and regenerating writes the same files. Commit `src/generated/` and
`Cargo.toml` together, and raise the crate's version in Cargo.toml when what it offers changes.

It needs [Bun](https://bun.sh) 1.4 and Node.js for generation, and the Rust toolchain
`rust-toolchain.toml` names (1.99.0). `openapi.json` is downloaded at generation time and not committed.
